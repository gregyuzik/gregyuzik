💬 **[AskKit](https://github.com/gregyuzik/AskKit)** — AI chat interface for SwiftUI apps: a complete Ask screen that answers from your app's data, with Apple's Foundation Models on Private Cloud Compute or on the device. A Swift package under the MIT license. iOS, iPadOS, macOS, and visionOS, and it builds for tvOS and watchOS too
